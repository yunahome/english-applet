# 微信云开发接入指南

本项目已完成云同步代码，但要让它真正生效，需要在微信开发者工具中完成以下一次性配置。

## 一、开通云开发环境

1. 打开**微信开发者工具**，导入项目（AppID 已设为 `wx9ed13f9f8cbcf771`）
2. 点击顶部工具栏的 **「云开发」** 按钮
3. 首次使用会提示开通，点击「开通」（免费额度够个人开发使用）
4. 记下你的**环境 ID**（形如 `cloud1-xxxxxx`，在云开发控制台左上角可见）

## 二、填入环境 ID

编辑 `src/services/cloud.ts` 第 8 行：

```ts
// 把空字符串换成你的环境 ID
const CLOUD_ENV = 'cloud1-你的环境ID'
```

> 不填也能正常本地运行，只是进度只存本地、不同步云端。

## 三、创建数据库集合

1. 云开发控制台 → **数据库** → 创建集合
2. 集合名填 `user_progress`
3. 权限设为「仅创建者可读写」（保证用户数据隔离）

## 四、部署云函数

在项目根目录 `cloudfunctions/` 下有两个云函数：`saveProgress`（保存）和 `loadProgress`（读取）。

1. 在微信开发者工具左侧资源管理器里，右键 `cloudfunctions/saveProgress` → **「上传并部署：云端安装依赖」**
2. 同样方式部署 `loadProgress`

## 五、验证

- 学完一关后，到云开发控制台 → 数据库 → `user_progress` 集合，能看到一条记录（openid + 红心/XP/通关记录等）
- 换一个微信号/真机登录，进度能自动恢复

## 数据字段说明

`user_progress` 集合文档结构（openid 为主键）：

| 字段 | 含义 |
|---|---|
| openid | 用户唯一标识（自动写入） |
| hearts | 红心数 |
| xp | 经验值 |
| streak | 连续天数 |
| lastStudyDate | 最近学习日期 |
| completed | 通关记录（object） |
| lastHeartRefillAt | 红心恢复时间戳 |
| updatedAt | 最后同步时间 |

## 同步策略

- **本地优先**：每次状态变化先写本地 Storage（即时生效）
- **节流上传**：3 秒内最多上传一次到云端
- **冷启动拉取**：打开小程序时从云端拉取，若云端更新则覆盖本地（换机恢复）
